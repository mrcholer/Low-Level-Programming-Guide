# Header Files

This topic is split into two parts:

1. **System headers** — headers provided by the operating system or standard library, such as `<unistd.h>`.
2. **Project headers** — headers you create for your own code, such as `myheader.h`.

Use the system headers section to learn how built-in headers work. Use the project headers section to learn how to write and organize your own headers.

## Parts

- [System Headers](01-system-headers/LESSON.md)
- [Project Headers](02-project-headers/LESSON.md)

Each section includes lesson content, a cheatsheet, and several examples that use only `write()`.
