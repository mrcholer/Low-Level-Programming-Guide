# Theory Index

This folder contains the full theory curriculum for low-level programming. The content is grouped into topic categories so you can follow related lessons together.

## Category overview

- [01-fundamentals](01-fundamentals/README.md) — basic computer concepts, compilation, and toolchain foundations.
- [02-data](02-data/README.md) — data representation, characters, strings, arrays, and core type concepts.
- [03-pointers](03-pointers/README.md) — pointer concepts, pointer arithmetic, and pointer-related behavior.
- [04-functions](04-functions/README.md) — functions, arguments, return values, and advanced function usage.
- [05-memory-management](05-memory-management/README.md) — stack vs heap, allocation, memory safety, and runtime behavior.
- [06-systems](06-systems/README.md) — system interfaces, file descriptors, standard IO, and system calls.
- [07-math](07-math/README.md) — arithmetic, Fibonacci, primes, square root, N-Queens, bitwise operators, and algorithm patterns.

## How to use this folder

Each topic folder contains:

- `LESSON.md` — the lesson content
- `CHEATSHEET.md` — the quick reference
- `EXAMPLE.md` — a practical example or visual canvas for the topic

Start with the fundamentals category, then move into data and pointers, followed by functions, memory management, and systems.
