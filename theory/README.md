# Theory Index

This folder contains the full theory curriculum for low-level programming. The lessons are grouped by topic so you can move from fundamentals to advanced systems topics in a steady order.

## Category overview

- [01-fundamentals](01-fundamentals/README.md) — computer basics, compilation, and toolchain foundations.
- [02-data](02-data/README.md) — data representation, characters, strings, arrays, and core type concepts.
- [03-pointers](03-pointers/README.md) — pointers, pointer arithmetic, and pointer safety.
- [04-functions](04-functions/README.md) — functions, arguments, return values, and function pointers.
- [05-memory-management](05-memory-management/README.md) — stack, heap, allocation, memory safety, and runtime behavior.
- [06-systems](06-systems/README.md) — file descriptors, standard I/O, and system calls.
- [07-math](07-math/README.md) — arithmetic, Fibonacci, primes, square roots, N-Queens, and bitwise patterns.

## Suggested learning order

1. Start with [01-fundamentals](01-fundamentals/README.md).
2. Continue with [02-data](02-data/README.md) and [03-pointers](03-pointers/README.md).
3. Move to [04-functions](04-functions/README.md) and [05-memory-management](05-memory-management/README.md).
4. Finish with [06-systems](06-systems/README.md) and [07-math](07-math/README.md).

## File guide

Each topic folder contains:

- `LESSON.md` — the main theory lesson
- `CHEATSHEET.md` — a quick reference summary
- `EXAMPLE.md` — practical examples and visual explanations
