# Arithmetic Cheatsheet

Operators:
- `+` add
- `-` subtract
- `*` multiply
- `/` divide
- `%` remainder

Important rules:
- use parentheses to control order
- integer division discards the fraction
- modulus gives the remainder

Examples:
- `sum = a + b;`
- `diff = a - b;`
- `size = count * sizeof(int);`
- `half = value / 2;`
- `remainder = value % 3;`
