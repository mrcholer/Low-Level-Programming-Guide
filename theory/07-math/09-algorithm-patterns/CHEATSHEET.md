# Algorithm Patterns Cheatsheet

Pattern summaries:
- Iteration: use loops for repeated work.
- Recursion: break a problem into smaller calls.
- Backtracking: try a choice, undo it, try another.
- Divide and conquer: solve smaller pieces and combine results.
- Greedy: choose the best local option.

Tips:
- Use arrays for puzzle state.
- Use functions to separate checks from actions.
- Test with small values before larger ones.

Common hard coding tasks:
- N-Queens
- Search and pathfinding
- Prime generation
- Sequence generation
