# Algorithm Puzzles and Hard Coding

Hard puzzles are a great way to practice problem solving with low-level code.

## Steps to solve a puzzle

1. understand the rules precisely.
2. choose the correct representation: arrays, matrices, or counters.
3. write a routine that tests whether a state is valid.
4. use loops or recursion to explore possible states.
5. backtrack when a choice leads to a dead end.

## Example problems

- N-Queens / Ten Queens
- Sudoku solver
- maze search / pathfinding
- prime number generator
- integer square root

## How low-level coding differs

- use plain arrays, not containers from a library.
- avoid expensive operations when possible.
- keep the logic explicit with simple loops and function calls.

## Hard code explanation

A hard coding problem is one where the solution needs both a clear algorithm and careful control of state. You can often break it down into these parts:

- data storage
- validity checks
- choice generation
- recursive exploration or repeated search
- cleanup and backtracking

## Practice

Try writing code for each step and printing intermediate states. That helps you understand the structure of the problem.
